# 固定韦特牌图与字体

牌图：Rider–Waite–Smith 历史牌组（1909），绘者 Pamela Colman Smith，设计 Arthur Edward Waite。

本包的七十八张牌图取自 mixvlad/TarotCards 的 rider-waite/720px 目录；该仓库逐牌文件以原始韦特名称命名，来源记为 Steve-P.org 的1909 Pam-A扫描整理，并将此牌组图片列为Public Domain。未包含其他牌组、现代商业再版或AI重绘。为减小技能包，以保留比例的方式缩至最高480×800、JPEG品质88；未改构图、人物、色彩设定或标志。assets/deck.json逐牌记录固定来源commit的URL、原始和打包后SHA256及尺寸。
