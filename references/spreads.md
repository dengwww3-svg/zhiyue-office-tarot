# 牌阵与牌位

以下主题牌阵是本技能的实用配置，不宣称是唯一标准。牌位顺序就是抽牌顺序。

| 情境 | 张数 | 依序牌位 |
| --- | --- | --- |
| 每日提醒／简单问题 | 1 | 当下值得注意的主题与行动；不做确定是非判决 |
| 一般困惑 | 3 | 现况、阻碍、可行下一步 |
| 过去至未来 | 3 | 过去影响、现在状态、既有条件延续的可能趋势 |
| 感情发展 | 6 | 自己的期待、对方互动倾向的象征、目前连结、指定期间的可能趋势、关系课题、自己的行动 |
| 人际沟通 | 5 | 自己的立场、另一方可能的立场、摩擦来源、共同基础、沟通方式 |
| 职涯发展 | 5 | 现况、可用优势、限制、可探索机会、下一步 |
| 两种选择 | 5 | 核心需求、A的可能收获、A的代价、B的可能收获、B的代价 |
| 学业准备 | 3 | 学习状态、主要瓶颈、改善策略 |
| 自我探索 | 5 | 目前感受、未被照顾的需求、反复模式、支持资源、小步行动 |
| 复合深入探索 | 9 | 自己的状态、对方互动倾向的象征、过往连结、分开原因的反思、当下阻碍、可修复之处、需要尊重的界线、条件式趋势、下一步 |
| 凯尔特十字 | 10 | 现况、交叉的挑战、深层基础、近期过去、意识中的目标、近期可能趋势、自身态度、外在环境、希望与担忧、条件式结果 |

六张牌的第四位涵盖整段期间，不能擅自把它拆成三个月份的预言。用户明确想逐月探索时，抽牌前改为「现况、第一月主题、第二月主题、第三月主题、阻碍、建议」，并提醒各月仅为象征性探索。

## 静态图布局

单张single；三张row或triangle；五张一般grid、两个选择choice；六张感情relationship；九张grid；十张celtic。位置顺序以抽前说明为准，不依图片的左右重新解读。三角是展示形态，不预设存在第三者。
