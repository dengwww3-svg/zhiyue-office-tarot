# 知月塔罗 Zhiyue Tarot

我是知月，陪你从牌里看看当下，也想想下一步。默认简体中文，可按每位用户的要求切换语言。

在同一段聊天中完成选题、确认抽牌、展示标准韦特牌图、逐位解读与补牌追问的 AI Skill。无须另外开启占卜网站或注册账号。

默认以温柔、清楚的简体中文回复；每位用户都可指定繁体中文、英文或其他语言，当前明确要求优先于旧偏好。文档示例不限制实际回复语言，也不会把某个人的偏好默认套用给所有人。塔罗用于自我探索与娱乐，不保证未来，也不能证实他人的内心。

## 可以做什么

- **不同主题**：感情、复合、工作、人际、两难选择、自我探索。
- **依问题选牌阵**：1～10张，包含三张牌、六张关系阵、五张选择阵、九张复合阵与凯尔特十字。
- **两种抽牌方式**：程序随机，或先洗牌再由用户选1～78的数字；等用户确认后才揭牌。
- **固定韦特牌图**：内附78张历史韦特牌图，依牌阵排成静态图片；逆位旋转180度，文字标签保持正向。
- **直接解读**：揭牌后立即解释牌义、正逆位与牌位，不需要再输入一次「帮我解读」。
- **清楚总结**：结尾提供「偏正向／偏负向／正负并存、暂不明朗」，说明依据及一个行动建议。
- **补牌与追问**：沿用原牌回答后续问题；明确要求补牌时，每次1～3张，沿用原副剩余牌、不重复、不覆盖原牌。
- **外部牌面**：用户可提供牌名或清楚照片，由 AI 解读；数字补牌与实体牌的来源会分开说明。
- **日历主题**：生日、情人节、520、七夕、长假前、假后收心、月度与年末整理。

## 快速开始

在已加载此 Skill 的 AI 对话中输入：

> 使用知月塔罗。我和对方已分开、没有联络，想看看近期的关系与未来一个月重新互动的空间。

AI 会先推荐牌阵与牌位。接著回复：

> 开始。

或者选择数字抽牌：

> 我想自己选。

AI 先建立固定牌堆，再请你输入对应张数的互异数字。解读后可以继续：

> 补一张，看我主动联络需要注意什么。

以上只是操作范例，没有预先指定牌面或结果。没有工具时，AI 必须明说采用文字模拟，不能冒充程序随机。

分享给朋友时，可让对方把下面这句话发给支持安装 Skill 的 AI：

> 请从 https://github.com/dengwww3-svg/nizi-tarot-skill 安装知月塔罗 Skill，找到 SKILL.md 所在目录，将该目录及 assets、references、scripts 等完整文件一并安装，并检查能否正常加载。

## 首次使用与主动提醒

第一次可说「你好」，或直接提问；有具体问题就先占卜，生日设定不会挡住流程。生日与提醒都可跳过。

简短设定范例：

> 我想开启生日和七夕提醒。生日是公历6月18日，生日当天上午9点提醒；七夕提前3天上午9点提醒，时区是 Asia/Shanghai。

这是示例日期，不是预填给所有人的设定。生日只收月、日，不要求出生年份；支持公历／农历，农历另确认是否为闰月。用户自行选择提醒类别，不预设全部开启。

**主动通知必须由宿主平台提供排程能力。** Skill 文件本身不会背景执行，不附通用通知伺服器，也不会因为上传 GitHub 就开始发通知。AI 只有在实际建立任务成功后，才能回复「已设定」。无排程工具时，只能在用户回来聊天时推荐近期主题。

- 公开节日资料可用来核对日期，不必读取私人行事历。
- 若要读取私人行事历，仍需宿主的日历连接、账号授权与用户提出的需求。
- 七夕、农历生日与官方连休要依目标年份核对；不能每年沿用同一公历日期。
- 2月29日、农历闰月或缺少30日等情况，先确认替代规则，不自行决定。
- 提醒只邀请用户回来；当次先了解近况／假期安排，等本人确认后才抽牌。
- 没有可持续储存的私有记忆时，不宣称能跨聊天、跨 AI 记住设定。

详细规则见 [生日与提醒](references/onboarding-reminders.md)、[日历模式](references/calendar-modes.md)。

## 安装与平台相容性

将整个文件夹交给支持 Skill 的宿主平台加载，**不要只复制 SKILL.md**，否则参考规则、图片与脚本会缺失。文件夹名称建议保留为 `zhiyue-tarot`。

Codex 本机环境可将文件夹放在 `~/.codex/skills/zhiyue-tarot/`；若自定义 `CODEX_HOME`，则使用该目录下的 `skills/zhiyue-tarot/`。确认根目录可直接找到 SKILL.md，再由宿主重新加载技能。

内部平台或其他 AI 请依其实际 Skill 汇入方式处理。此专案提供可携的 Markdown 规则与 Python 脚本，**不是一个能自动替所有 AI 增加工具的应用程序**。

| 宿主能力 | 可用体验 |
| --- | --- |
| 只有文字 | 问题分析、文字模拟／外部牌面解读、总结与追问 |
| Python 3.9以上＋私有临时目录 | 固定牌堆、程序随机、数字选牌与同局补牌 |
| 再加 Pillow＋附件显示 | 标准牌图与静态牌阵 |
| 网路或可靠历法工具 | 核对未内建年份的节日与农历日期 |
| 私有记忆／排程工具 | 依实际支持能力保存偏好、建立与修改提醒 |

核心对话不绑定模型品牌；图片、真随机、记忆与提醒是否可用，取决于宿主。无对应能力时必须如实降级，不能保证所有 AI 的执行效果完全相同。

## 开发与验证

在本文件夹执行：

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

抽牌及日历脚本只使用 Python 标准函式库；Pillow 用于排图及图像测试。脚本使用方式见 [会话指南](references/session-guide.md) 与 [牌图指南](references/cards-and-images.md)。

日历脚本目前内建2026年中国大陆连休／补班资料，以及2026、2027年的七夕日期。其他年份或地区会标示待核实，不能视为已涵盖所有日历。

目前包含35项自动测试，涵盖78张牌唯一性、选牌顺序、错误不改牌堆、补牌不重复、状态恢复、日期边界、牌图对应、各种排版与逆位旋转。这些测试不代表已验证每一种 AI 或内部平台。
